# Verelay 1.3.0

LiveTranslate Bridge 正式更名为 **Verelay**，并启用全新的应用图标和宣传图。

- 应用、工程、安装包与主页统一采用 Verelay。
- 保留原有设置、API Key、会话历史和录音；无需重新配置。
- GitHub 仓库迁至 [hoobnn/verelay](https://github.com/hoobnn/verelay)，旧仓库链接继续重定向。
- Homebrew 包名改为 `verelay`，tap 提供旧包名迁移映射。
- 旧版自动更新入口保留兼容更新源，更新到本版后使用新的更新地址。

```sh
brew install --cask hoobnn/tap/verelay
```

已安装旧包的 Homebrew 用户可先运行 `brew update`，再运行 `brew upgrade --cask verelay`。
